# Ecos de Aetheria

RPG 2D original creado con Godot 4. Aldea Brumal es la primera zona de exploración.

## Prototipo actual
- Exploración top-down y controles táctiles.
- Cuatro criaturas originales.
- Encuentros en hierba alta.
- Combate por turnos: atacar, técnica, vínculo y huir.
- Equipo de hasta tres criaturas, experiencia y guardado local.

## Ejecutar
Abrir `project.godot` en Godot 4.3 o posterior y ejecutar la escena principal.

## Android
El flujo de GitHub Actions valida el proyecto y prepara la exportación Android. La APK solo se considera lista cuando la tarea de exportación termina correctamente; esta primera entrega es un prototipo y requiere pruebas en dispositivo.
